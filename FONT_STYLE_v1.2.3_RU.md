# LeafGreen Complete — шрифт EN/RU в оригинальном стиле (v1.2.3)

Исправление относится только к **пиксельным шрифтам**, не к координатам меню и не к переводам.

## Что изменено

- Кириллические глифы уменьшены до размеров оригинального шрифта Pokémon FireRed/LeafGreen (обычная ширина ~5–6 пикселей, широкие буквы до 8).
- Совпадающие по начертанию кириллические и латинские символы (`А/A`, `В/B`, `Е/E`, `Н/H`, `О/O` и др.) взяты **побайтно** из оригинального английского атласа для соответствующего размера.
- Недостающие русские буквы нарисованы вручную на целочисленной пиксельной сетке с тем же основным контуром и однопиксельной серой тенью. Никакой интерполяции или масштабирования нет.
- У обычных и маленьких шрифтов выровнены базовая линия, верхняя высота заглавных и ширина символов. Поддержаны 33 заглавные + 33 строчные буквы, включая `Ё/ё`, `Й/й`, `Ъ/ъ`, `Щ/щ`.
- Английские PNG, тексты, CSV переводов и геометрия меню не затронуты.
- Файл `src/russian_glyph_widths.generated.inc` пересчитан по новому рисунку букв. Его надо обновлять вместе с PNG, иначе в меню появятся неправильные интервалы.

## Проверки

- Все 16 автоматизированных тестов переводчика и наград пройдены.
- Все четыре графических PNG конвертируются штатным `tools/gbagfx/gbagfx` в `.fwlatfont` / `.hwlatfont`.
- Все 19 пар совпадающих по форме русских и латинских букв проверены на точное совпадение пикселей.
- Полная сборка ROM и реальное отображение в My Boy! **не проверялись**. Для этого потребуется GitHub Actions + тест на телефоне.

## Как использовать, если Python не установлен

1. Распакуй `LeafGreen-v1.2.3-Original-Style-Fonts-Hotfix.zip` **в папку с Git-репозиторием** с заменой файлов. Старый `LeafGreen_reward_flow_fix.patch` обратно не копируй.
2. В PowerShell: `cd C:\PokemonLeafGreenComplete-git`, затем `git status --short`, `git add -A`, `git commit -m "Match Cyrillic fonts to original FRLG pixel style"`, `git push origin main`.
3. Дождись GitHub Actions → новой успешной сборки и загрузи ROM в My Boy!.
4. Проверь русские `НАСТРОЙКИ`, `РУССКИЙ`, `БЕЗ СМЕНЫ`, `ЁЖ ЙЦ ЩЪ ЬЫ ЮЯ`, затем English. Для чистоты сравнения отключи сглаживающие фильтры в My Boy!.

Если исправления кладёшь в старую папку исходников, а репозиторий — в отдельной папке, переноси **только файлы из hotfix**, не весь старый репозиторий целиком.
