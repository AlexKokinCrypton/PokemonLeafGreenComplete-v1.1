# LeafGreen Complete v1.2.1 — исправления EN/RU (без Python на ПК)

Исправлено:
- Строка CANCEL теперь внутри рамки: окно OPTIONS снова 12 тайлов высотой, расстояние между 8 строками — 11 пикселей.
- Устранено повреждение верхней подсказки/«белая полоска»: окно OPTION больше не перекрывает видео-тайлы соседнего окна (проверка 0x36 + 26*12 == 0x16E).
- Кириллица Normal/Male/Female/Small заменена на чёткие пиксельные растры, без ресайза старого донорского шрифта.
- build_bilingual.py при запуске без параметров не размывает/не перегенерирует новые растры, только проверяет их и пересчитывает ширины.
- Английские исходные шрифты и тексты сохранены без изменений.

Для установки из PowerShell:
1. Распакуйте архив LeafGreen-v1.2.1-UI-Hotfix.zip в корень клонированного git-репозитория (с заменой файлов).
2. cd C:\PokemonLeafGreenComplete-git
3. git status --short
4. git add -A
5. git commit -m "Fix bilingual options layout and sharpen Cyrillic fonts"
6. git push origin main
7. GitHub → Actions → новый Build LeafGreen (EN/RU) → Artifacts → pokeleafgreen.gba

Проверяйте: EN → RU → EN, CANCEL в рамке, смену параметров стрелками, запись языка в SAVE и повторное открытие меню.
Старые сохранения рекомендуется предварительно скопировать в резерв.

Локальные тесты: 15/15 passed, валидация 11968 строк без ошибок, GBA-атласы переконвертированы. Запуск новой ROM в эмуляторе на этой машине не выполнялся.
