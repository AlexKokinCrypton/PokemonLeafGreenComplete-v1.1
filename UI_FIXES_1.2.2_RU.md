# LeafGreen EN/RU — UI Hotfix 1.2.2

Исправления по игровому тестированию в My Boy! на Android:

- Восемь пунктов Options выводятся с шагом 13 px (вместо 11 px): английские буквы больше не перекрываются следующим пунктом.
- Заголовок и верхняя строка подсказки остаются на прежнем месте. Нижняя рамка заголовка и верхняя рамка настроек теперь занимают одну общую строку тайлов, поэтому область настроек увеличена до 13 тайлов без наложений.
- Списки и значения печатаются строго от констант `OPTION_LABEL_X` и `OPTION_VALUE_X`.
- Области буферов окон переразмещены: 0x02–0x31, 0x32–0x169, 0x16A–0x1A5; графика рамки начинается с 0x1AA.
- Кириллица заменена на чёткие монохромные глифы без серого размытого края; английские PNG и строки не изменены.

## Проверка

1. Открой новую ROM в My Boy! с обычным сохранением (`.sav`), не старым save state.
2. Настройки EN: все 8 строк, включая CANCEL, без подрезания, без артефактов при смене параметров.
3. Переключи Language -> РУССКИЙ. Левый столбец должен начинаться с одной вертикали, правый — с другой.
4. Проверь СКОР. ТЕКСТА / АНИМАЦИЯ / БЕЗ СМЕНЫ / ВЫХОД и все строки с Д, Щ, Й, Ё.
5. Верни ENGLISH и перезапусти игру, проверь сохранение языка.

Проверены статические размеры и тесты Python на исходниках. Полноценное визуальное тестирование ROM на устройстве не выполнялось.
