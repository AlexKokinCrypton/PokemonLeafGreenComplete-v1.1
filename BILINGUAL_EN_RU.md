# LeafGreen Complete — двуязычность EN / RU

## Что подключено в исходниках

- **English**: оригинальные шрифты и строки не перезаписываются.
- **Русский**: кириллица из трёх донорских растровых шрифтов Normal, Male, Female; дополнительно создан уменьшенный Small.
- 66 символов кириллицы (`А–Я`, `а–я`, включая `Ё/ё`) имеют отдельную двухбайтовую кодировку `F9 80 … F9 C1` — в неиспользуемой области `CHAR_EXTRA_SYMBOL`. Отдельные русские глифы не конфликтуют с английскими буквами, эмодзи и управляющими последовательностями.
- Поддерживается смешанный текст: русские буквы + английские названия + `{PLAYER}` / `{STR_VAR_1}` + коды `\n`, `\p`, `\l` и т. п.
- В **OPTIONS** добавлен выбор **LANGUAGE → ENGLISH / РУССКИЙ**. Язык сохраняется в двух ранее свободных байтах `SaveBlock2.filler_90`, размер/поля существующих сохранений не смещены. Для старых сохранений язык по умолчанию English.
- Английские строки без русского перевода отображаются по-английски: нет пустых заглушек и подмены непереведённых сообщений.
- 21 строка меню настроек переведена для проверки механизма. Остальные строки требуют перевода через HTML-редактор.
- `StringExpandPlaceholders`, `AddTextPrinter` и `GetStringWidth` проверяют каталог русских вариантов, чтобы скрипты, окна и вычисление ширины текста использовали согласованный язык.

## Как работать с переводом

**Не установлен Python?** Используйте [браузерный редактор и GitHub Actions](БЕЗ_PYTHON_ИНСТРУКЦИЯ.md). Для пользователя не требуется локальная установка Python или GBA toolchain.

1. Откройте `tools/localization/leafgreen-offline-editor.html` в обычном браузере.
2. Переводите строки. Игровые вставки/коды в редакторе заблокированы.
3. Нажмите «Скачать CSV» и сохраните как `localization/en_ru.csv`, заменив текущий файл.
4. Выполните в корне репозитория:

   ```bash
   python tools/localization/translate.py validate
   python tools/localization/build_bilingual.py --texts-only
   make leafgreen
   ```

5. При необходимости пересоздания растровых кириллических шрифтов установите Pillow (`python -m pip install Pillow`) и запустите `python tools/localization/build_bilingual.py` без `--texts-only`.

`build_bilingual.py` создаёт ресурс `src/localization_ru.generated.inc` только для валидных переведённых строк **с доступными глобальными символами C/ASM**. Локальные/статические строки пока не могут подключаться автоматически; список таких строк (если они переведены) появляется в `localization/UNMAPPED_TRANSLATIONS.txt`.

## Ограничения и обязательное QA

- Это интеграция **исходников**, а не подтверждение того, что весь переведённый ROM работает. Успешная сборка ROM пока не проверена: в окружении отсутствует GBA toolchain (`agbcc` / `arm-none-eabi-as`).
- Кириллические шрифты конвертированы штатным `gbagfx`; точное отображение/перенос строк надо проверить в GBA-эмуляторе. Длинные переводы потребуют ручной правки разбиения на строки, так как экран GBA узкий.
- Автоматическое сопоставление по адресу оригинальной строки охватывает глобальные строковые символы. Статические строки и часть составных UI-строк всё ещё требуют отдельной интеграции. Полная локализация **11 968** текстов ещё не завершена.
- Имя, введённое через игровой экран именования, по-прежнему использует стандартную латиницу: русская экранная клавиатура не добавлялась.
- Менять язык рекомендуется в меню вне активного текста; текущее окно может сохраниться до закрытия (данные сохраняются после выхода из OPTIONS и последующего обычного сохранения игры).
- Для окончательной версии проверить: EN и RU на новой и старой сохранёнке, переключение EN→RU→EN, отображение `{PLAYER}` и других плейсхолдеров, работу магазинов и наград, сохранение/загрузку, меню/боевые сообщения, длинные русские строки.
