# Как собрать LeafGreen EN/RU без Python на своём компьютере

**Локально нужны только браузер и доступ к GitHub.** Вся обработка CSV, тестирование и попытка сборки GBA ROM выполняются на сервере GitHub Actions. Локально не требуются Python, Pillow, `make`, `agbcc` или ARM-компилятор.

## 1. Переводить

1. Открой `tools/localization/leafgreen-offline-editor.html` двойным кликом — он работает без установки программ и без интернета.
2. Переводи строки. Защищённые игровые коды (`{PLAYER}`, `\n`, `$` и т. д.) редактор не даёт менять.
3. Нажимай «Сохранить строку» для фиксации редактирования на странице.
4. Нажми «Скачать CSV» и сохрани новый файл **`en_ru.csv`**.
5. При следующем редактировании используй кнопку «Загрузить CSV», чтобы продолжить работу с последнего сохранённого файла.

> Редактор не записывает изменения в исходники автоматически: важно **скачать CSV** и загрузить его в репозиторий.

## 2. Обновить CSV на GitHub

1. Открой свой репозиторий на GitHub (с исходниками этого ZIP, файлы должны лежать в корне репозитория, а не во вложенной папке ZIP).
2. Перейди в папку `localization/`.
3. Через **Add file → Upload files** загрузи новый `en_ru.csv` вместо предыдущего, затем нажми **Commit changes**. Если GitHub предлагает редактировать существующий файл или загрузить замену другим способом, важно сохранить точный путь `localization/en_ru.csv`.
4. Открой вкладку **Actions → Build LeafGreen (EN/RU)**. Запуск происходит автоматически при коммите в ветку `main`; также можно нажать **Run workflow**.
5. Успешный запуск: открой результат workflow и скачай артефакт **`PokemonLeafGreenComplete-EN-RU`**. В нём будет `pokeleafgreen.gba`.

Если сборка завершается ошибкой, открой красный шаг workflow: не каждый исходник с новыми изменениями обязательно собирается без дополнительных исправлений. Успешная подготовка переводов **не означает** проверку ROM в эмуляторе.

## 3. Что происходит автоматически

- Проверяется актуальность английского оригинала и неприкосновенность управляющих кодов.
- Запускаются тесты локализации и проверок наград.
- Из CSV генерируется `src/localization_ru.generated.inc`, не переписывая английские строки.
- GitHub Actions устанавливает GBA-инструменты и пытается собрать ROM.
- Если сборка успешна, GitHub сохраняет файл ROM в артефактах.

**Ограничение текущей локализации:** некоторые статические/локальные строки ещё не имеют автоматического соответствия; в логе будет указано количество пропущенных переводов. Большая часть каталога ещё ожидает перевода. Переключение EN/RU и отображение русских шрифтов в новой ROM требуют реальной проверки в эмуляторе.

**Примечание:** GitHub Actions использует Python **на сервере GitHub**, а не на компьютере пользователя. Достаточно аккаунта GitHub и разрешённых Actions для репозитория.
