# Перевод LeafGreen Complete: английский + русский

## Автономный HTML-редактор (рекомендуемый способ)

**Сборка без Python на компьютере:** см. [`БЕЗ_PYTHON_ИНСТРУКЦИЯ.md`](../БЕЗ_PYTHON_ИНСТРУКЦИЯ.md). GitHub Actions сам запускает валидатор, генератор переводов и компилятор.

1. Откройте двойным щелчком `tools/localization/leafgreen-offline-editor.html` в любом современном браузере. **Ничего устанавливать и запускать не требуется.** Все 11 967 строк уже включены в HTML-файл.
2. Найдите диалог или интерфейсную строку в панели слева. Английский оригинал отображается только для чтения; русские слова редактируются в полях справа. Игровые коды показываются неизменяемыми плашками. Символы `{`, `}`, `\`, `$`, `"` и реальные переводы строк в полях ввода заблокированы.
3. Нажмите **«Сохранить строку»**. Это сохранит изменения **в памяти страницы**, но ещё не на диск.
4. Нажмите **«Скачать CSV»** и замените полученным `en_ru.csv` файл `localization/en_ru.csv` внутри репозитория. Лучше предварительно сохранить резервную копию каталога.
5. При следующем открытии HTML нажмите **«Загрузить CSV»** (либо перетащите сохранённый CSV на страницу), чтобы продолжить с последней версии перевода. Встроенный первоначальный каталог не обновляется сам собой.

Для CSV поддерживаются UTF-8 (с BOM и без), экранированные кавычки, запятые и многострочные значения. Гарантия сохранности исходных английских файлов распространяется на оба редактора: они работают только с каталогом переводов, а не с английскими исходниками игры.

## Вариант с автоматической записью CSV через локальный сервер Python

Нужен **Python 3.9+**. Дополнительные библиотеки не нужны.

Из корня репозитория в терминале запустите:

```bash
python3 tools/localization/translate.py serve
```

Откройте в браузере адрес **http://127.0.0.1:8765**. На Windows команда также может выглядеть как `py tools/localization/translate.py serve`.

- Слева доступен поиск по английскому тексту, русскому переводу, файлу и идентификатору.
- В центре — оригинальная английская строка (только чтение).
- Справа можно редактировать исключительно обычные слова между **заблокированными** фрагментами.
- Подстановки `{PLAYER}`, `{STR_VAR_1}`, управляющие коды `{COLOR BLUE}`, переводы строки `\n`, `\p`, `\l`, другие escape-последовательности и `$` **нельзя редактировать или удалять**. Они визуально отображаются в защищённых плашках. Сохранение восстанавливает их по оригиналу, а не по пользовательскому вводу. Добавить новые управляющие коды в текстовые поля также нельзя.
- Нажмите «Сохранить перевод». Он попадёт в **`localization/en_ru.csv`**. Оригинальные английские `.inc`, `.c`, `.h` не изменяются.
- Чтобы откатить русский вариант выбранной строки, нажмите «Сбросить русский перевод».

## Обновление каталога после изменений в исходниках

```bash
python3 tools/localization/translate.py export
python3 tools/localization/translate.py validate
```

`export` повторно сканирует текстовые ресурсы и сохраняет существующий русский перевод по устойчивым ID. При изменении английского источника отмечает строки для повторной проверки. Для полного экспорта отдельных RU-ресурсов в staging (не в ROM):

```bash
python3 tools/localization/translate.py build
```

При необходимости проверить защиту игровых токенов:

```bash
python3 -m unittest discover -s tools/localization -p 'test_*.py'
```

### Важно: редактор не является готовой проверенной двуязычной ROM

**Сейчас** исходники содержат кириллический шрифт, выбор языка в Options и генератор таблицы EN/RU. Скрипт `translate.py build` создаёт только отдельные RU-ресурсы для предварительного просмотра; для сборки ROM используйте автоматический GitHub Actions или `build_bilingual.py --texts-only` перед `make leafgreen`. Успешная ROM и её работа в эмуляторе ещё не подтверждены.

Часть текста и графики в игре создаётся динамически или задаётся через графические ресурсы; данный каталог покрывает найденные `.string` и `_("...")` в ресурсах `data/`, `src/`, `include/`, но **не все потенциальные игровые надписи**.
